Discord DSA bot UI reference

Source-derived inventory of every current command, modal, select, button, embed family, and lifecycle DM. Command responses are ephemeral. Lifecycle notifications are ordinary private DMs because Discord does not support ephemeral DMs.

Source: apps/bot/src/commands.ts Source: apps/bot/src/ui.ts Source: apps/bot/src/interactions.ts Source: apps/bot/src/notifier.ts Updated: 28 July 2026
Visual language. The bot uses Discord-native embeds with no author strip, banner, or decorative image. Profile avatars and server icons are used as thumbnails. Blurple means informational, orange means review, yellow means in progress, green means success/actioned, red means failure/rejection, and grey means closed without action.

Shared report flow

  1. Access checkAdmin/whitelist bypass or at least one credit.
  2. Resolve targetMessage snapshot, profile account, or server metadata.
  3. Report modalReason, affected elements, and brief/final text.
  4. CountrySaved override, explicit override, or DeepSeek Auto.
  5. DraftResearch/write, manual path, refine, regenerate, or edit.
  6. Orange reviewTruthfulness warning and final 512-character content.
  7. SubmitReserve credit, create API report, then observe status.
  8. Status + DMHistory embed, durable updates, outcome reply, optional retry.

Report creation commands

/report message

Inputs: required message link, optional country, optional dont-use-ai.

  1. Modal: Report MessageReason + brief/final report.
  2. Resolve messageBest-effort message evidence snapshot.
  3. AI/manual branchWriting status or direct review.
  4. Review message reportOrange review embed and controls.
  5. Message reportFinal status/history embed.
Apps → Report Message

The message context command pre-fills the message URL and message snapshot.

  1. Selected Discord messageURL and snapshot captured.
  2. Modal: Report MessageReason + brief/final report.
  3. AI/manual branchCountry and content preparation.
  4. Review message reportOrange review embed and controls.
  5. Message reportFinal status/history embed.
/report profile

Inputs: raw user ID, optional observed server ID, country, and AI opt-out.

  1. Resolve user IDFetch username, display names, bot flag, and avatar.
  2. Account confirmationFound or unsuccessful lookup embed.
  3. Modal: Report ProfileReason, profile elements, and brief.
  4. Review profile reportOrange review with avatar thumbnail.
  5. Profile reportStatus/history plus submitted account name.
/report server

Inputs: server ID/invite or current server, country, and AI opt-out.

  1. Resolve serverBest-effort name, description, counts, and icon.
  2. Modal: Report ServerTarget if missing, reason, server elements, brief.
  3. AI/manual branchCountry and content preparation.
  4. Review server reportOrange review with server summary/icon.
  5. Server reportStatus/history with resolved server details.

  3. Report browserOne full report embed per page.
  4. Previous / NextButtons when more than one report exists.

  1. Fetch reportVerify ownership or administrator access.
  2. Message/Profile/Server reportComplete status and history embed.

Modal and component inventory

Report Message/Profile/Server modal

Always includes report reason and a 1–512 character brief/final report.

  • Message link appears only when it was not already supplied.
  • Profile reports add a required multi-select of unlawful profile elements.
  • Server reports add the target when missing and a required multi-select of server elements.
  • AI copy says a vague reason is acceptable; manual copy says this is the final report.

Refine AI report modal

One 1–512 character paragraph: “What should DeepSeek change?” It continues the existing conversation.

Edit report manually modal

Displays the current AI candidate for copying, including a truncation notice when necessary, then accepts a final 1–512 character report.

Country picker

A required single-select with 24 entries per page. Auto is present only for AI-enabled reports. Previous and Next appear when needed.

Review controls

Submit DSA Report, Refine, Regenerate, Edit manually, Cancel, and Change country. Manual reports omit Refine and Regenerate.

Report browser controls

Previous and Next appear for multi-report lists. Retry as new report appears only for safe, eligible failures below the retry limit.

Lifecycle DM flow

  1. SubmittedSend one status embed and save its Discord message ID.
  2. ReceivedEdit that same embed; do not create a second status message.
  3. OutcomeEdit the embed to green/grey/red and reply beneath it.
  4. Receipt timeoutEdit red, reply with the two-minute explanation, show retry.
  5. Pre-ID failureSend plain text with failure detail and internal report ID.
  6. ReconciliationWebhook events plus a 15-minute paginated API event feed.
